# Meu Repertório

PWA simples com 34 músicas organizadas por estilo, busca, favoritos e acordes resumidos.

## Testar no Mac
Abra `index.html` no navegador para testar localmente. Para instalar no iPhone como PWA, publique esta pasta em um endereço HTTPS (por exemplo, GitHub Pages) e abra no Safari; use Compartilhar > Adicionar à Tela de Início.

## Cifras
O botão “Cifra” abre uma busca direcionada ao Cifra Club para a música e o artista. Confira a versão, tonalidade e afinação com a gravação que você toca. Algumas sequências do catálogo estão marcadas como provisórias ou “a confirmar”.
